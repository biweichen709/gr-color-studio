GR 色彩工坊 · 使用说明
========================

双击 GRColorStudio.exe 即可运行，无需安装 Python。适用于 Windows 10/11（64 位）。

首次运行时 Windows 可能提示「Windows 已保护你的电脑」：这个程序没有购买代码签名证书。
点「更多信息」→「仍要运行」。程序完全离线运行，不联网、不收集任何数据。


一、风格调色（马上能用）
------------------------
1. 左侧选择风格：
   哈苏 HNCS 风格（近似）：HNCS 自然 / HNCS 人像 / HNCS 风光
   富士胶片模拟风格（近似）：PROVIA 标准 / Velvia 鲜艳 / ASTIA 柔和 / Classic Chrome 经典正片 /
                             Classic Neg 经典负片 / Nostalgic Neg 怀旧负片 / ETERNA 电影 /
                             ETERNA 漂白 / PRO Neg. Std 人像负片 / REALA ACE 真实
   黑白：ACROS 黑白 / ACROS + 红滤镜 / 单色 标准 / 棕褐色
2. 「打开照片」：支持 JPG、PNG、TIFF，以及 DNG（GR 的 RAW）、PEF、NEF、CR2、ARW、RAF 等。
   没打开照片时显示内置色卡。上方可切换「效果 / 原图 / 左右对比」。
3. 用「强度 / 色温 / 色调 / 对比 / 饱和 / 褪色」微调，「重置微调」回到预设本身。
4. 「导出照片」：高质量 JPEG，保留 EXIF（拍摄参数、方向）和色彩描述文件。
   「批量处理文件夹」：处理整个文件夹，结果放在该文件夹下的「GR色彩工坊_风格名」子文件夹，按 Esc 取消。
   「导出 .cube」：导出 LUT（33 或 65 精度），可用于 Photoshop（颜色查找）、DaVinci Resolve、
   Final Cut Pro、Premiere 等支持 .cube 的软件；Lightroom 需先在 Camera Raw 里把它做成配置文件。
   「导入 .cube」：使用你自己的 LUT，微调滑块同样有效。

说明：
· 这些预设是依据公开描述手工调校的近似风格，不含哈苏、富士或理光的任何数据，与这些公司无关。
  名称只用来说明风格方向。
· 照片按 sRGB 处理。颗粒、暗角、锐化属于空间效果，不在色彩风格里。
· 预设的设计基准是相机直出 JPEG。RAW 文件先做中性显像再套风格，效果会比直出更平一些，可用「对比」补偿。


二、写入相机（实验功能，请先读完）
----------------------------------
目标：把当前风格写进 GR IV 机内的某个影像风格，例如替换 Positive Film。

原理：不刷固件。按照 GitHub 项目 radium-wang/ricoh-gr4-firmware-analysis-and-feature-expansion 的
实机研究，在工厂菜单开启 Script 后，相机开机会执行 SD 卡上的 script/startup.ttl，
可以读写机内 A: 资源盘。本程序只做文件级的「备份 → 替换 → 读回核对 → 随时恢复」。

必须知道：
· 生成的相机脚本只在电脑端模拟验证过，尚未在真机上运行。第一次只做「1. 备份」。
· 理光的色彩表在哪个文件、是什么格式，目前还不知道。「2. 扫描」只给候选，需要你实拍确认。
  如果色彩表不在 A: 盘的独立文件里，这条路就走不通，请不要尝试改固件。
· 程序强制：只写 A: 盘；只写已备份并校验过的文件；新文件必须与原文件等长；每次写入一次性执行
  并读回逐字节核对；卡上原有文件不会被删除，只会移到 RC_OLD 文件夹。
· 用 FAT32 格式的 SD 卡，电量充足。出现校验失败时不要反复重试，先查看日志。
· 每台机身单独使用一个工作文件夹，备份的原件请再另存一份。

步骤（界面上 0～5 一一对应）：
0. 选择工作文件夹和 SD 卡根目录。按参考项目说明放好工厂菜单入口文件，开机按住 MENU 进入工厂菜单，
   只把 Script 设为 Enable。
1. 从理光官网下载 GR IV 固件（fwdc248b.bin），点「从官方固件提取候选路径…」，程序会列出固件引用的
   全部相机文件并按可能性排序填入；也可手动填写。然后生成备份脚本 → 卡插入相机开机一次 →
   卡插回电脑 → 校验备份。
2. 扫描备份，选出「基准表」（例如 Standard）和「替换槽位」。
3. 生成替换文件写入 SD 卡 → 开机一次 → 校验写入 → 实拍检查。
4. 想恢复时：生成恢复脚本 → 开机一次 → 校验恢复。
5. 收尾：移走启动脚本，在工厂菜单把 Script 设回 Disable。

日志保存在工作文件夹的 log.txt；程序出错时的详细信息在 %TEMP%\GRColorStudio-error.log。
